# AirPods Battery

Простое Android-приложение на React Native для проверки заряда AirPods.
Показывает заряд левого и правого наушника, кейса и признаки зарядки.
Поиск запускается кнопкой и прекращается при получении показаний для наушников
и кейса; время поиска ограничено 8 секундами. Приложение работает без интернета
и не ведёт поиск в фоне.

Добавлено распознавание открытых сообщений AirPods 1–5, AirPods Pro 1–3 и AirPods Max 1–2, включая варианты ANC, Lightning и USB-C. Доступность заряда зависит от передаваемого формата; зашифрованные сообщения кейса без ключа не читаются. У Max отображается один аккумулятор без кейса. Проценты приблизительные, с шагом 10%.
Для проверки кейса открой крышку с наушниками внутри рядом с телефоном.
На Android 12 и новее требуется только разрешение «Устройства поблизости».
На Android 11 и старше для BLE-поиска требуется местоположение.

## Сборка APK

Нужны Node.js 22, Java 17 (JDK, для создания ключа подписи) и аккаунт Expo.
Android SDK на компьютере не требуется: APK собирается в Expo EAS.

В папке проекта:

```powershell
npm ci
npm run setup:android
npx eas-cli@25.3.0 login --no-browser
npx eas-cli@25.3.0 build -p android --profile preview
```

`setup:android` один раз создаёт секретный ключ подписи и настройки сборки.
Сохрани `android/app/release.keystore` и `credentials.json` отдельно от Git.
Для сборки обновлений на другом компьютере перенеси эти же файлы.
Если создать другой ключ, старое приложение придётся удалить перед установкой.

Готовый APK доступен по ссылке из EAS. Сборка рассчитана на Android-устройства
с архитектурой arm64, включая Samsung Galaxy A35. Установленному приложению
интернет и подключение к компьютеру не нужны.
